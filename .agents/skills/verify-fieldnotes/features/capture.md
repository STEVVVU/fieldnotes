# Browser capture

## Sub-features

Inherited article, selection, bookmark, screenshot and PDF capture. Fieldnotes adds a separate article/selection evidence contract and a constrained background broker.

## How to get to it (user POV)

Install a built web clipper in a disposable supported browser profile, configure the isolated server and invoke its popup on an owned fixture page.

## Driving it with an installed extension

Build with `pnpm --filter web-clipper build`. A real extension host is required. IAB does not establish installation/control of this MV3 extension. Do not report happy-dom tests, a standalone popup document or HTTP ingestion as installed-extension acceptance.

Use the helper's `evidence`, `restart`, `verify` and `cleanup` commands to prove the production server route, exact bytes, manifest, replay handling and zero server-side missing-image fetches. That path is verified separately. A full installed-extension journey must additionally preview the real article or selection, check source and destination, preserve it, reopen the note, and confirm attachments. Exercise a lost receipt with **Retry this capture**, navigation, missing document IDs, destination changes and untrusted content-script requests.

## Gotchas

Current CUA inventory exposes IAB and MCP Apps only. Actual capture and content-script abuse checks remain blocked until a supported browser with this build loaded is controllable.
